## 把游戏运行起来

需要 Go 1.26.11、Node.js 24、pnpm 10.33.0 和 GNU Make，命令在仓库根目录执行

```bash
make web-install
make web-build
make embed-spa
make embed-spa-check
make content-compile
make content-verify
make dev
```

启动后打开 [http://localhost:8080](http://localhost:8080)。手机访问、容器运行及环境配置见 [快速开始](docs/快速开始.md)

## 为训练员准备的细节

| 功能 | 说明 |
| --- | --- |
| 一份个人设置 | 昵称和头像全站通用，六位房间编号区分同名玩家 |
| 三种语言 | 简体中文、繁體中文、日本語，角色名称与提示按地区适配 |
| 桌面与手机 | 宽屏表格与分栏，窄屏卡片与单列，作答内容保持一致 |
| 进度与重连 | 支持的单人玩法可导出、导入与续玩，联机恢复后读取已确认记录 |
| 按需配置 | 玩法、容量、匹配大厅和 Cloudflare Turnstile 可分别设置 |
| 语音格式 | **40 kbps VBR、Opus / WebM** |

<summary>项目结构与数据流</summary>

React 页面负责交互与单人挑战；Go 服务管理联机出题、作答与裁决，SQLite 保存房间与结果。题库独立编译，可按站点需要开放玩法

![项目结构与数据流](docs/public/media/architecture-zh-Hans.svg)

| 目录 | 用途 |
| --- | --- |
| `web/` | React · TypeScript · Vite |
| `internal/` | Go · SQLite · SSE / WebSocket |
| `cmd/` | 启动、备份与题库编译 |
| `data/` | 资料、来源与修订记录 |
| `api/` | OpenAPI |
| `docs/` | VitePress |

第三方账户登录为默认关闭的实验性功能，支持 OAuth 2.0／OIDC。特雷森挑战赛与训练员挑战榜目前为界面框架，后端尚未接入
