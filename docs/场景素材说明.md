## 加工与显示

现有图像按最长边约 1600px、JPEG 质量 65 的方式转换；补充或替换时记录原图来源、摘要与转换参数，不直接覆盖而丢失溯源。macOS 转换示例：

```bash
sips -s format jpeg -s formatOptions 65 -Z 1600 input.png --out output.jpg
```

页面按容器裁切，并使用独立遮罩保护文字可读性。手机和资源失败时回退页面底色或渐变，不让缺图破坏布局；不要将 CSS filter 加在整个内容容器上导致文字一起模糊

装饰不遮挡焦点、弹层与主按钮，不引入自动闪烁或大幅视差。需要动效时尊重减少动态设置，并先验证真实低性能设备
