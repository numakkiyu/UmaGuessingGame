角色、美术、官方标识及声音的权利归相应权利人，主要涉及 Cygames 及相关创作者。本项目为非官方同人项目，非商业用途说明不等于取得授权；再发布、二次加工或商业使用前必须自行核查权利与上游要求

本地题包可包含经校验的头像、牌面和必要 UI 资源；部分显示也可能尝试受控远端来源并回退本地资源，音频按内容准入处理。不能因资源存在于公开 URL 就推定可以无限下载、直链或重新分发

场景清单见[背景映射](场景素材说明.md)，数据说明见[资料快照](../data/wiki/README.md)。来源清单应记录 URL、原文件名、摘要及转换过程；摘要只能证明文件一致，不能证明许可成立
