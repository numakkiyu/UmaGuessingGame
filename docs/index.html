这是面向 GitHub 的静态演示页，用来展示项目定位、技术架构和部署入口。 正式可游玩的完整版本仍建议部署到支持 Next.js、PostgreSQL 与 Redis 的运行环境。

查看 GitHub 仓库 阅读 README

项目亮点

  • 单人模式已经具备完整对局、分享和只读查看链路。
  • 多人匹配与好友对战已经补齐房间、同步和状态面板基础。
  • 图片采用受控回源与本地缓存复用策略。
  • 仓库自带中文部署文档和标准 GitHub 协作模板。

技术架构

  • Next.js 16 + React 19 + TypeScript
  • PostgreSQL + Drizzle ORM
  • Redis + Cloudflare Turnstile
  • Docker Compose / PM2 / Nginx

推荐部署方式

  • Windows / macOS：优先 Docker Desktop
  • Linux 正式环境：Docker Compose 或 PM2 + Nginx
  • 面板运维：宝塔面板或 1Panel
