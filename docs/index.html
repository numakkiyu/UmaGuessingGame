Uma Guessing Game

和朋友一起猜，今天轮到哪位马娘登场。

这里是赛马娘猜猜乐的项目主页。你可以先看看游戏的整体风格，再根据自己的设备和环境， 选择合适的方式把它部署起来，搭一个能和朋友一起游玩的站点。

查看项目仓库 开始部署
  • 一个人玩 随时开一局
  • 和朋友分享 带上房间码一起看
  • 自己部署 Windows、Linux、macOS 都能搭

如果你想先了解项目，可以从这里查看说明和文档。

如果你想把站点真正搭起来给大家玩，直接从下方部署入口开始就行。

For Players

这个项目适合谁

喜欢猜角色的玩家

  • 输入一位马娘，看看这一猜离答案还有多远
  • 适合自己慢慢猜，也适合在群里轮流挑战
  • 结束后可以回看这一局的结果与记录

想搭给朋友玩的维护者

  • 仓库里已经整理好了部署文档和环境配置模板
  • 可以按自己的服务器环境选择普通部署或 Docker 部署
  • 也可以按面板文档，用宝塔或 1Panel 来搭建
