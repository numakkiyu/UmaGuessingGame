# 创意企划

课间的企划会开始啦！抽到角色、场景和限制后，用 80 字写个点子，匿名展示给大家。参赛者票与观众票合计选出创意奖

![创意企划](../public/media/play/creative-zh-Hans-desktop.webp)

## 怎么玩

1. 和朋友开局，阅读抽到的角色、场景和限制
2. 在规定时间内写一个 80 字以内的点子，查看输入框的字数提示
3. 提交后作品锁定，随后阅读匿名作品并为其他玩家投票
4. 票数揭晓后评选创意奖，同票并列；正式加分以开局约定为准

## 规则与计分

- 每队抽取角色 + 普通场景 + 限制，90 秒内写一段不超过 80 字的企划
- 最多 80 字，首尾空白不计，组合表情可能占多个字，以输入框旁的计数为准。超出时请精简后再投稿
- 作品匿名展示，投票 30 秒。每位参赛玩家可投一票，不能投自己或本队的作品
- 队票与观众票分开统计；同一个人可能使用多台设备，票数不等于实际参加人数
- 主持人预审，违规或空内容会被跳过；落选作品的玩家仍然参与下一题
- 创意奖按参赛者票与观众票合计评选，同票并列，没有有效票就不颁奖。默认不计入总分；若设有正式加分，只看参赛者票，观众票不参与

## 手机上玩

在输入框中写企划，留意字数；作品公布后，再选择想投票的作品
