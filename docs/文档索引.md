# 文档索引

本文档用于说明当前公开文档的阅读顺序、目标读者和更新时机。

## 一、推荐阅读顺序

### 适合第一次接触项目的人

1. [README.md](../README.md)
2. [快速开始.md](./快速开始.md)
3. 按平台选择部署指南

### 适合准备正式部署的人

1. [技术架构说明.md](./技术架构说明.md)
2. [Linux部署指南.md](./Linux部署指南.md)
3. [第三方依赖与资料来源.md](./第三方依赖与资料来源.md)

### 适合准备参与维护的人

1. [CONTRIBUTING.md](../CONTRIBUTING.md)
2. [维护与更新指南.md](./维护与更新指南.md)
3. [技术架构说明.md](./技术架构说明.md)

## 二、当前文档一览

| 文档 | 目标读者 | 主要内容 |
| --- | --- | --- |
| `README.md` | 所有人 | 项目概览、架构、部署入口、文档导航 |
| `快速开始.md` | 新维护者 | 最快拉起项目的方法 |

| `第三方依赖与资料来源.md` | 所有人 | 依赖、资料来源、版权与致谢 |

## 三、什么时候更新这些文档

### 必须更新 README 的情况

- 项目定位变化
- 部署入口变化
- 新增或移除主要模式
- 技术栈发生重大变化

### 必须更新部署文档的情况

- Docker 结构变化
- 新增环境变量
- Nginx / PM2 / 面板部署方式变化
- 一键脚本行为变化

### 必须更新架构与维护文档的情况

- 新增核心模块
- 数据流变化
- 权限或安全边界变化
- CI 或协作流程变化
