# 语音素材

角色语音用于[听音辨马](play/audio.md)：听台词，为每段选择说话的角色。语音采用 **40 kbps VBR、Opus / WebM**，扩展名为 `.webm`

## 内容与播放

题目使用已试听并核对说话人与台词的片段。开始挑战前准备语音，点击播放后收听；播放次数与计分规则见玩法说明

语音支持离线保存，后续在同一浏览器中可以继续使用已保存的素材

## 格式参数

| 项目 | 设置 |
| --- | --- |
| 目标码率 | 40 kbps VBR |
| 编码与容器 | Opus / WebM |
| 采样率 | 48 kHz |
| 声道 | 单声道 |
| HTTP 类型 | `audio/webm; codecs=opus` |
| 文件限制 | 每段最多 60 秒、2 MB |

## 素材维护

| 路径 | 内容 |
| --- | --- |
| `data/assets/audio/library/` | WebM 语音文件 |
| `data/assets/audio/manifest.json` | 来源、文件摘要、大小与时长 |
| `data/manual/audio-clips.review.json` | 说话人、台词与试听核对记录 |

校验完整素材库：

```bash
pnpm run audio:verify
```

命令逐段解码并核对清单，CI 执行相同检查。题包按审校记录选用语音，流程见[参与贡献](参与贡献.md)
