# 快速开始

这份文档适合第一次接触赛马娘猜猜乐的维护者、开发者和部署者。

如果你只想尽快把项目跑起来，建议先看这里；如果你准备正式部署到服务器，请继续阅读：

- [Windows 部署指南](./Windows部署指南.md)
- [Linux 部署指南](./Linux部署指南.md)
- [macOS 部署指南](./macOS部署指南.md)

## 运行前你需要什么

### 所有平台通用

- Git
- Node.js 22 或更高版本
- npm
- `.env.example` 里对应的环境变量配置

### 推荐再准备

- Docker 与 Docker Compose V2
- PostgreSQL
- Redis

> 项目在开发环境下支持一定程度的本地回退，但对外部署时仍建议准备正式的 PostgreSQL 与 Redis。

## 5 分钟拉起开发环境

```bash
git clone https://github.com/numakkiyu/UmaGuessingGame.git
cd UmaGuessingGame
cp .env.example .env
docker compose -f docker-compose.dev.yml up -d --build
```

默认地址：

- 应用：`http://localhost:3000`
- PostgreSQL：`localhost:5432`
- Redis：`localhost:6379`

## 纯命令行启动

如果你不打算使用 Docker，也可以使用命令行部署：

```bash
npm install
npm run prepare:data
npm run db:push
npm run db:seed
npm run dev
```

如果要验证生产构建：

```bash
npm run build
npm run start
```

## 环境变量说明

项目根目录下的 [`.env.example`](../.env.example) 已经加入中文注释，重点配置包括：

- `APP_BASE_URL`：站点对外访问地址
- `ASSET_BASE_URL`：静态资源基础地址
- `DATABASE_URL`：PostgreSQL 连接串
- `REDIS_URL`：Redis 连接串
- `TURNSTILE_*`：Cloudflare Turnstile 配置
- `ENABLE_MULTIPLAYER`：多人匹配开关
- `ENABLE_FRIEND_BATTLE`：好友对战开关
