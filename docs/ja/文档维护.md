# ドキュメントサイトの管理

VitePress で簡体字中国語、繁体字中国語、日本語のドキュメントを公開します。README は GitHub で表示できる Markdown を使用します

## ファイル構成

| パス | 用途 |
| --- | --- |
| `README.md` | 簡体字中国語の紹介 |
| `README.zh-Hant.md`・`README.ja.md` | 繁体字中国語・日本語の紹介 |
| `docs/*.md` | 簡体字中国語の文書 |
| `docs/zh-Hant/`・`docs/ja/` | 繁体字中国語・日本語の文書 |
| `docs/.vitepress/config.mts` | 言語、ナビゲーション、検索、公開パス |
| `docs/.vitepress/theme/` | ホームページとテーマ |
| `docs/public/media/` | スクリーンショットと紹介画像 |

同じ記事は各言語で同じファイル名を使い、言語メニューから対応するページに切り替えられます。説明と名称は地域に合わせ、API やコードの識別名は変更しません

## ローカルで起動

リポジトリのルートで実行します

```bash
pnpm --dir docs install --frozen-lockfile
pnpm docs:dev
```

表示された URL を開きます。ドキュメントの依存はゲームのフロントエンドとは別にインストールします

```bash
pnpm docs:check
pnpm docs:build
pnpm docs:preview
```

既定のパスは `/UmaGuessingGame/` です。カスタムドメインなどでは `DOCS_BASE` を指定できます

```bash
DOCS_BASE=/ pnpm docs:build
```

## GitHub Pages

`.github/workflows/pages.yml` が `docs/` のロック済み依存をインストールし、`docs/.vitepress/dist/` を公開用にアップロードします

リポジトリの Settings → Pages で Source を GitHub Actions に設定します。`main` の CI が成功すると、そのコミットを自動公開します。手動実行でも現在の main の CI 成功が必要です。パスは Pages 設定から取得します

Pages はドキュメント専用です。ゲームとオンライン API は[クイックスタート](快速开始.md)に従って別に起動します

## 画像と文章

README は相対画像パス、表、`<picture>`、折り畳み表示を使用します。GitHub は任意の CSS やスクリプトを実行しないため、複雑なレイアウトはサイト側に置きます

スクリーンショットは実際の画面を使用し、言語を合わせます。アドレスバー、個人アカウント、試験用ダイアログは含めません。装飾キャラクターは既存素材を使い、[出典と利用条件](第三方依赖与资料来源.md)を記録します

紹介ページには遊び方と使い方、子ページには設定と技術資料を置きます。生成ファイル、依存キャッシュ、一時レポートは Git に含めません

ロゴは `public/media/party-logo.webp`、16:9 のメインビジュアルは `party-keyvisual.webp` を使用します。文字を含まない共通画像を三言語で利用します。ゲーム側のロゴは `web/public/assets/ui/branding/` に配置し、差し替える際は同じファイルを両方に反映します

## 種目ガイドとフォント

`docs/play/`、`docs/zh-Hant/play/`、`docs/ja/play/` に言語別の種目ガイドを置きます。画像は `docs/public/media/play/` に種目・言語・端末別で保存します

フォントはゲームとサイトそれぞれの `public/fonts/` に置き、地域ごとの字形を使います。一般的な文字を先に読み込み、拡張文字は必要時に取得します。[出典とライセンス](第三方依赖与资料来源.md)
