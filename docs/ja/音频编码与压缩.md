# 音声素材

キャラクターのボイスを[声当て](play/audio.md)で使用します。台詞を聴いて、話しているウマ娘を選びます。音声形式は **40 kbps VBR、Opus / WebM**、拡張子は `.webm` です

## 内容と再生

試聴し、話者と台詞を確認した音声を出題します。開始前に音声を準備し、再生ボタンで聴きます。再生回数と採点方法は種目の説明をご覧ください

音声はオフライン保存に対応し、同じブラウザーで保存済みの素材を引き続き使えます

## 形式と設定

| 項目 | 設定 |
| --- | --- |
| 目標ビットレート | 40 kbps VBR |
| コーデックとコンテナー | Opus / WebM |
| サンプリング周波数 | 48 kHz |
| チャンネル | モノラル |
| HTTP タイプ | `audio/webm; codecs=opus` |
| ファイル上限 | 1本あたり60秒、2 MB |

## 素材の管理

| パス | 内容 |
| --- | --- |
| `data/assets/audio/library/` | WebM 音声ファイル |
| `data/assets/audio/manifest.json` | 出典、ファイルのハッシュ、サイズ、長さ |
| `data/manual/audio-clips.review.json` | 話者、台詞、試聴の確認記録 |

ライブラリー全体を確認するコマンド：

```bash
pnpm run audio:verify
```

全音声をデコードしてリストと照合し、CI でも同じチェックを実行します。問題パックでは確認記録に基づいて音声を採用します。手順は[コントリビュート](参与贡献.md)をご覧ください
