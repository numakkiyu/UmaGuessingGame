# 開発コマンド

変更対象に応じて単体テスト、静的解析、ビルドを実行できます。リポジトリのルートで使用します

| コマンド | 用途 |
| --- | --- |
| `make test` | Go の単体・結合テスト |
| `make test-race` | データ競合の検出 |
| `make fmt-check` | Go の書式 |
| `make vet` | Go の静的解析 |
| `make web-typecheck` | TypeScript の型 |
| `make web-lint` | ESLint とクラス名 |
| `make web-copy-check` | 画面文言 |
| `make web-test` | UI・保存・スクリプトのテスト |
| `make web-build` | フロントエンドのビルド |
| `make embed-spa` | Go への画面の埋め込み |
| `make embed-spa-check` | 埋め込み内容との比較 |
| `make web-size` | 配信ファイルのサイズ |

内容関連のテストは[コンテンツパック](内容编译.md)を読み込みます。画面を埋め込むテストは `make web-build` と `make embed-spa` の出力を使用します。`make web-install` はアプリと独立した開発ツールの依存をインストールします

## API・データ・画面

```bash
pnpm --dir web run api:check
go run ./cmd/content contract --spec api/openapi.json --routes
go test ./internal/e2e/... -count=1
make content-compile
make content-verify
pnpm run audit:layout
```

レイアウトツールは Playwright と独立した実行インスタンスを使用します。接続先の指定は `web/scripts/audit-layout.mjs` を参照してください。スクリーンショットやレポートは Git に含めません

## ドキュメント

```bash
pnpm --dir docs install --frozen-lockfile
pnpm docs:dev
pnpm docs:check
pnpm docs:build
pnpm docs:preview
```
