# 行動規範

Issue、Pull Request、レビューなど、本プロジェクトの協力の場に適用します。地域、言語、経験を問わず参加を歓迎します

## 大切にすること

- 再現できる問題や根拠を示し、改善案を話し合う
- 言語や地域、身元、経験の違いを尊重する
- 素材や資料の出典を示し、他者の成果を自作としない
- 個人の好み、ルール、アクセシビリティを区別して意見を交換する

侮辱、嫌がらせ、差別、脅迫、スパム、個人情報の公開、運営者の許可のないゲームサーバーへの攻撃は認めません。Cookie、確認コード、DB、非公開セッション、他のプレイヤーを特定できる情報は公開しないでください

素材の権利や資料、呼び名に意見があるときは、出典と変更案を添えてください。ゲーム内のやり取りを現実の個人への攻撃に持ち込まないでください

## 問題が起きたとき

場所、時刻、秘密情報を除いた経緯をメンテナーへ知らせてください。脆弱性は[非公開の報告方法](安全策略.md)を使用します

メンテナーは影響に応じて注意、修正依頼、交流の制限、投稿の削除などを行えます。関係者のプライバシーを保ち、対象者も指定の窓口で事情を説明できます。メンテナーにも同じ規範が適用されます

GitHub の規約と適用法令も引き続き適用されます
