# 対応ブラウザー

Safari、Firefox、Chrome、Edge の最新版をおすすめします

| ブラウザー | 最低バージョン |
| --- | --- |
| Safari | 17.4 |
| Firefox | 128 |
| Chrome | 111 |
| Edge | 111、Chromium 版 |
| iPhone / iPad | iOS / iPadOS 17.4 |

Internet Explorer と EdgeHTML 版 Edge はサポート対象外です。表は読み込み条件を示しており、実際の動作は端末や設定によって異なります

## ゲームを開く

ブラウザーの言語に合わせて日本語、簡体字、繁体字を選びます。言語メニューからの変更も可能です。古いバージョンでは更新方法と公式ダウンロード先を案内します

## 音声と保存

音声は再生ボタンを押すと流れます。聞こえない場合は端末の音量、タブのミュート、再生権限を確認してください

一人用の進行状況は同じブラウザーで続けられます。サイトデータを消す前に記録をエクスポートしてください。オフライン機能には安全な接続が必要です。設置には HTTPS をおすすめします

## 開けないとき

通信状況を確認してから再読み込みしてください。回答を送信済みの場合は、元の対局で記録を確認してから操作を続けてください
