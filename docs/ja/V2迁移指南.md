# V2 への移行

V2 は独立したデータモデルと実行方式を使います。旧版の環境変数、データベース、キャッシュはそのまま転用できません

## 引き継げるもの

| データ・資源 | 扱い |
| --- | --- |
| キャラクターと問題資料 | 現行形式と出典を確認し、問題データを再ビルド |
| 旧 PostgreSQL | 独立したバックアップを保持。自動インポートは未対応 |
| 旧セッション・進行中ルーム | 現行の匿名 ID や対局として引き継がない |
| 画像・音声 | 出典、ライセンス、内容確認、ハッシュを照合 |
| ドメイン・HTTPS | 新サービスの Origin とプロキシ設定を作成 |
| 運用スクリプト | 引数、保存先、ヘルスチェックを現行仕様に合わせる |

## 切り替え

1. 旧プログラム、DB、設定、素材をバックアップ
2. [クイックスタート](快速开始.md)に従い、独立した実行ディレクトリーを作成
3. 現行の画面と問題データをビルドし、内容を検証
4. PC とスマートフォンで参加・回答・結果を確認
5. ドメイン、HTTPS、Origin と容量を設定して転送先を変更
6. 旧環境とバックアップを保持し、問題があれば一式を戻す

成績を移す場合は別途、項目の対応、本人性の関連付け、重複排除を実装します。同じニックネームだけで同一人物とは扱いません

## V2 の更新

V2 内にも DB、問題データ、ルールのバージョンがあります。適用済みの移行ファイルは変更せず、新しい移行を追加します。復元方法は[運用と更新](维护与更新指南.md)にあります
