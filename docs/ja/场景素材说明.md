# 背景素材

ロビー、結果画面、大画面表示の周囲に使う背景です。問題、表、盤面、主なボタンには読みやすい地色を用意します

## ファイル

| ファイル | 元の識別名 | 用途 |
| --- | --- | --- |
| `lobby-classroom.jpg` | `Bg_0001_01113.png` | 桜の教室、ロビー |
| `results-riverside.jpg` | `Bg_0243_03110.png` | 秋の川辺、結果画面の周囲 |
| `event-stage.jpg` | `Bg_0366_00000.png` | 大会用大画面のステージ |

Cygames の美術素材を含みます。出典、ダイジェスト、利用条件は素材リストで管理します

## 変換と表示

既存画像は長辺約 1600px、JPEG 品質 65 を目安に変換しています。macOS の例です

```bash
sips -s format jpeg -s formatOptions 65 -Z 1600 input.png --out output.jpg
```

表示領域に合わせてトリミングし、文字の後ろに独立したマスクを重ねます。画像取得に失敗しても地色やグラデーションで表示を保ちます。内容全体にぼかしを適用せず、キーボードフォーカスやダイアログを覆わないようにします

動きは OS の「視差効果を減らす」などの設定に対応させ、連続点滅を避けます
