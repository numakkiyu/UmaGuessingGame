# セキュリティ方針

現行の V2 コードを保守対象とします。旧構成のオンライン環境については、その運営者に確認してください。ここでは実装とデプロイの条件を説明し、安全性と処理容量は実際の環境で評価します

## 脆弱性の報告

GitHub の **Security → Report a vulnerability** から非公開で報告してください。無効な場合は、Issue で非公開の連絡方法を問い合わせ、攻撃手順や認証情報は公開しないでください。固定の応答期限は定めていません

対象コミット、デプロイ方法、最小再現手順、影響範囲、秘密情報を除いたログを添えてください。第三者の環境を走査したり、接続を占有したり、非公開データを取得したりしないでください

## 配置と秘密情報

公開時は HTTPS と Secure Cookie を使用し、Origin と信頼するプロキシの CIDR を明示します。転送ヘッダーを無条件に信頼しません。DB はローカルディスクに置き、一つのプロセスで所有します。データ、鍵、バックアップ、環境設定は静的配信から分離します

`/metrics` は既定でループバックからのみ接続でき、`UMA_METRICS_LOCAL_ONLY` で制御します。プロキシからの接続元がループバックでも、外部への公開は別途制限してください。HTTP、接続、キュー、入力サイズの上限を保持し、非 root コンテナーと永続ボリュームを使用します

`verified-keys.json` は DB と一緒に保護・バックアップします。停止後に旧鍵を残し、32 バイトのランダム鍵を Base64URL パディングなしで追加して `active` を変更します。最大 8 鍵です。旧鍵は最後の関連チケットの期限からさらに 24 時間以上保持し、旧受領記録が不要になってから削除します

鍵ファイルが破損した場合は元ファイルを保持し、サービスを停止してバックアップを確認します。作り直すと既存の署名付きチケットを検証できなくなります

## 身元と対局

匿名 Cookie が身元の認証情報です。名前、ルームコード、六桁番号、IP、ブラウザー特性は本人確認の代わりになりません。Cookie 削除や別ブラウザーで新しい身元が作られる場合があります

一人用の答えと記録はブラウザーから読めるため、正式な対戦成績へ取り込みません。対戦の出題と判定はサーバーで行い、クライアントが得点、勝利、期限を決めることはできません。書き込みトランザクション内でセッション、所属、役割、操作権限を再確認します

通知接続は完全な所属を確認し、退出と参加枠の復元で失効します。通常は 30 秒ごとにも確認します。機密状態の取得と操作には別の権限確認があり、一時的な DB 障害を不正の証拠にはしません

CSP、Origin、CSRF、HttpOnly Cookie、入力制限は注入や不正リクエストを減らします。開発者ツールや拡張機能の使用を理由に敗北扱いにしません。公開知識の検索や自動回答、ブラウザーを制御できる利用者を完全に防ぐものではありません。大規模攻撃にはプロキシや CDN 側の保護も必要です

ローカル保存データのチェックサムは破損の検出用です。正式な成績はサーバーで判定します。通知接続は変更だけを伝え、期限切れや役割の変更は次の再確認まで反映されない場合があります。機密データの取得と操作は別途、その都度認可します

## 任意の入場確認

Turnstile は既定で無効です。有効時はサーバーで Siteverify を使い、ホスト名、操作、期限を確認します。秘密鍵と生トークンを公開設定・ログに残しません。使用記録をセッションへ結び付け、期限と容量を設けます

異常判定は認証済みセッション自身の制限履歴を使います。確認成功で通常のリクエスト制限を解除しません

確認中でも、自分のマッチング取消・対戦拒否・退出・降参は可能です。認証、Origin／CSRF、頻度制限、所有権を確認します。対戦の承認、他のメンバーの削除、待機の延長には異常確認を適用します。リスク状態と通行証のバージョンを同時に更新し、新しい異常は旧証明を失効させます。Turnstile を無効にしても、通常の認可と容量制限は維持します

## アカウントと更新

外部ログインは既定で無効の実験的機能です。HTTPS、固定コールバック、バックエンドの環境変数を使用します。上流トークンは該当するサーバーリクエスト内だけで扱い、アカウント Cookie と匿名プレイ Cookie を分離します

依存と基盤のセキュリティ情報を継続して確認してください。設定方法は[設定リファレンス](配置参考.md)、鍵やログインは[アカウント](账户登录与游玩准入.md)、復元は[運用と更新](维护与更新指南.md)を参照してください
