## 選擇遊玩方式

| 方式 | 如何開始 |
| --- | --- |
| 單人挑戰 | 從首頁選擇玩法，準備資料後開始 |
| 好友遊玩 | 建立房間後分享代碼，暱稱與頭像全站通用 |
| 隨機配對 | 選擇賽制加入佇列，人數到齊並全員確認後自動開局 |
| 派對模式 | 由主持人安排隊伍、玩法與回合，支援大螢幕顯示 |

## 儲存與交卷

「儲存作答」記錄這版答案，截止前仍可修改；交卷則送出目前答案並立即結束。單人時間到時依最後儲存的答案計分

連線對局在收卷或時間到後統一揭曉。猜謎、翻牌、占格、編隊與策略賽道各有完成條件

## 連線與勝負

短暫斷線時請保持頁面開啟，恢復後先確認作答紀錄。倒數會繼續，重新載入不增加時間

雙人猜角色共用謎底，先猜中者獲勝；一方用完次數後等待對方。任一方認輸，對手立即獲勝。其他計分玩法依各頁規則結算，同分並列

## 題目與資料

角色資料、初始適性、原型馬血統與史實賽事依收錄來源出題。卡牌費用、九格計分與策略賽道屬於本專案的同樂規則
