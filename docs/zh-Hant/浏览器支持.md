# 瀏覽器支援

建議使用最新版本的 Safari、Firefox、Chrome 或 Edge

| 瀏覽器 | 最低版本 |
| --- | --- |
| Safari | 17.4 |
| Firefox | 128 |
| Chrome | 111 |
| Edge | 111，Chromium 版 |
| iPhone / iPad | iOS / iPadOS 17.4 |

Internet Explorer 與 EdgeHTML 版 Edge 已停止支援。以上為載入條件，實際體驗也會受到裝置與瀏覽器設定影響

## 開啟遊戲

頁面會自動選擇繁體中文、簡體中文或日本語，也能從語言選單切換。版本過舊時會顯示更新方法與官方下載連結

## 聲音與儲存

聽音玩法需要點選播放。聽不到時，請確認裝置音量、網頁靜音狀態與播放權限

單人挑戰能儲存進度，請使用同一瀏覽器繼續。清除網站資料前可先匯出紀錄。離線功能需要安全連線，部署建議使用 HTTPS

## 頁面打不開時

先確認網路，再嘗試重新載入。若已送出答案，回到原對局確認紀錄後再繼續
