# 設定參考

設定分為部署 JSON、程序參數與 Compose 插值。Go 不會自動讀取 `.env`，Compose 只傳入 `environment` 列出的變數

## 優先順序

`--config` 優先於 `UMA_CONFIG` 選擇檔案。可覆寫的欄位依 JSON、環境變數、顯式命令列參數的順序套用。JSON 拒絕未知欄位與錯誤型別，修改後重啟生效

```bash
UMA_SECURE_COOKIES=true \
UMA_ALLOWED_ORIGINS=https://uma.example.com \
go run ./cmd/server --config config/cloud.json --addr 127.0.0.1:8080
```

容器內的設定路徑為 `/etc/umaguess/cloud.json`，宿主機的路徑依掛載位置設定。完整旗標見 `go run ./cmd/server --help`

## 程序變數

以下為直接執行 Go 的預設值，Make 與 Compose 可覆寫路徑和監聽設定

| 變數 | 預設值 | 用途 |
| --- | --- | --- |
| `UMA_ADDR` | `127.0.0.1:8080` | HTTP 監聽位址 |
| `UMA_DATA_DIR` | `./data/runtime` | 資料庫、鎖與簽章金鑰 |
| `UMA_CONTENT_DIR` | `./content` | 內容包根目錄 |
| `UMA_WEB_DIR` | `./web/dist` | 前端目錄 |
| `UMA_BACKUP_DIR` | `./backups` | 備份輸出 |
| `UMA_DEPLOYMENT` | `lan` | 部署形式，可由 JSON 指定 |
| `UMA_LOG_LEVEL` | `info` | 日誌層級 |
| `UMA_SECURE_COOKIES` | `false` | HTTPS 公開服務設 true |
| `UMA_ALLOWED_ORIGINS` | `—` | 完整 Origin，以逗號分隔 |
| `UMA_TRUST_PROXY` | `false` | 信任指定代理的轉發標頭 |
| `UMA_TRUSTED_PROXY_CIDRS` | `—` | 可信代理網段 |
| `UMA_ALLOW_MISSING_ORIGIN` | `false` | 受控非瀏覽器寫入例外 |
| `UMA_METRICS_LOCAL_ONLY` | `true` | 指標僅允許回環連線 |
| `UMA_SESSION_TTL` | `168h` | 匿名連線期限 |
| `UMA_DISPLAY_TTL` | `12h` | 展示連線期限 |
| `UMA_BUSY_TIMEOUT` | `1s` | SQLite 等待時間，Go duration |
| `UMA_SYNCHRONOUS` | `FULL` | SQLite 持久性 |
| `UMA_READ_CONNS` | `8` | 讀取連線池 |
| `UMA_QUEUE_CAPACITY` | `128` | 單房指令佇列 |
| `UMA_SHUTDOWN_GRACE` | `15s` | 正常停止等待 |

`UMA_PUBLIC_ORIGIN` 表示公開網址，允許來源仍由 `UMA_ALLOWED_ORIGINS` 明確設定。可信代理只填實際網段，不使用 `0.0.0.0/0` 或 `::/0`

## 玩法開關

`config/lan.json` 用於受控區域網路，`config/cloud.json` 提供保守的公開服務設定。`forms` 的 `local`、`verified`、`solo`、`friend`、`matchmaking`、`event` 分別控制單人挑戰、既有驗證挑戰、單人房、好友、配對、活動。`modes` 再限制各玩法

任一層關閉便限制新入口，仍須符合人數與題庫條件。Cloud 預設關閉配對與活動。帳號排行榜與 `forms.verified` 是不同功能

## 容量

| limits | LAN | Cloud | 作用範圍 |
| --- | --- | --- | --- |
| `connections` | 2000 | 300 | 全站連線 |
| `connectionsPerRoom` | 220 | 32 | 單房連線 |
| `connectionsPerSession` | 2 | 2 | 單會話連線 |
| `playersPerRoom` | 100 | 16 | 單房玩家 |
| `spectatorsPerRoom` | 100 | 12 | 單房觀眾 |
| `queuedCommands` | 4096 | 512 | 全站處理中與等待的命令 |
| `rateLimitBuckets` | 20000 | 10000 | 全站限流桶 |
| `verifiedChallenges` | 512 | 128 | 全站進行中的驗證挑戰 |
| `sessionCreatePerIPMinute` | 600 | 120 | 同 IP 每分鐘建立會話 |
| `sessionCreatePerIPBurst` | 200 | 30 | 同 IP 建立會話突發額度 |

數字是保護上限，依硬體與活動調整，非吞吐量承諾。同出口 IP 可能有多名玩家，IP 不作身分判斷

`limits.apiRequests` 控制一般請求並行數，`requestPerIPMinute`、`requestPerIPBurst` 限制來源請求。連線另按全站、房間、會話限制，公開服務可搭配 CDN、反向代理與 WAF

## 隨機配對

```json
{
  "matchmaking": {
    "lobbyEnabled": true,
    "queueCapacity": 1000,
    "proofBits": 16,
    "idleEnabled": true,
    "idleSeconds": 60
  }
}
```

`lobbyEnabled` 控制大廳與公開統計，`forms.matchmaking` 控制新排隊。`queueCapacity` 預設 1000，上限 10000。`proofBits` 預設 16、範圍 12–20，填 0 使用預設，工作量驗證不可關閉

工作量題綁定目前身分與賽制，90 秒有效、使用一次，由 Worker 計算 SHA-256。排隊為 120 秒、確認 20 秒、在場租約 35 秒、每 3 秒續約，取消或確認逾時冷卻 15 秒

`idleEnabled` 預設 true，`idleSeconds` 預設 60、範圍 15–300。從開放作答起，全場沒有有效提交才取消，不計勝負；好友與派對不受此設定影響

大廳每 5 秒讀取統計，後端快取最多 2 秒，只包含各賽制的排隊、確認、對局人數與房間數

## Cloudflare Turnstile

`turnstile.enabled` 預設 false。開啟時填 `siteKey`、允許的 `hostnames`，金鑰由 `secretEnv` 指定的環境變數讀取，預設 `UMA_TURNSTILE_SECRET`

`operations` 控制建房、加入、排隊、挑戰與活動的入場確認。`grantSeconds` 預設 900、範圍 60–3600；`maxConcurrent` 控制並行確認；`browserSignals`、`signalPerMinute`、`signalBurst` 是選用輔助訊號與額度

自適應設定 `adaptive` 預設 true，`riskThreshold` 預設 6、範圍 3–100，`riskWindowSeconds` 預設 60、範圍 10–600。僅使用已認證會話自身被限流的紀錄，不以共用 IP、擴充功能或開發工具判負

正常入場用淺色卡片，異常時用暗幕與紅色邊緣提示。使用官方控制項，不能注入內部 CSS、裁切或遮蓋標識。停用時不載入驗證腳本、不留空白版位

### 控制項外觀與視窗變更

目前採官方淺色主題與 `appearance: "always"`，外層卡片、插圖與狀態文字由專案樣式控制。Cloudflare 的 `interaction-only` 和 Enterprise Offlabel 為官方選項，現行頁面未採用

驗證尚未完成時，尺寸檔位變更會重新準備控制項；已完成或正在送出時保留結果。關閉面板或離開頁面會停止舊的恢復工作，避免它覆蓋新面板。掛載後 45 秒仍未取得結果且未進入人工互動時，顯示重試與返回入口；人工互動不受此準備逾時中斷

## Compose

`UMA_HOST_PORT` 預設 8080，容器內監聽 `:8080`。其他金鑰變數須透過 Compose 明確傳入。`UMA_RUNTIME_IMAGE`、`UMA_BUILD_GO_PROXY` 為建置參數，正式容器採用 distroless 非 root 映像；停止等待為 30 秒，應長於應用程式的 15 秒

## 實驗性帳號

預設檔省略 `accounts`。啟用、登入預設、Cookie 與各玩法登入要求見[帳號登入](账户登录与游玩准入.md)。設定錯誤會拒絕啟動，關閉的登入方式不顯示

挑戰賽與挑戰榜目前只有介面元件，未提供計分後端或部署開關，勿加入尚未支援的 `scoredChallenges`、`leaderboards` 等欄位
