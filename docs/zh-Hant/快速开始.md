# 快速開始

下載原始碼後，可在電腦或伺服器執行遊戲。本頁的指令都在儲存庫根目錄執行

## 執行環境

- Go 1.26.11 或相容的新版本
- Node.js 24、pnpm 10.33.0，用於前端建置
- GNU Make；Windows 可使用 WSL2
- Docker Compose v2 為可選方式

## 首次啟動

```bash
make web-install
make web-build
make embed-spa
make embed-spa-check
make content-compile
make content-verify
make dev
```

開啟 `http://localhost:8080`，停止時在終端機按 Ctrl+C。`make dev` 預設監聽 `:8080`，資料寫入 `.cache/runtime`

`.cache/runtime` 為開發用目錄。需長期保留的資料請另外設定持久路徑並定期備份

`make web-install` 會安裝應用程式與 `web/tools/toolchain/` 的兩組鎖定依賴。直接執行 `go run ./cmd/server` 時，預設監聽 `127.0.0.1:8080`，資料寫入 `data/runtime`

## 修改前端

後端執行時，另一個終端機啟動

```bash
pnpm --dir web run dev
```

開啟終端機列出的 Vite 網址，預設為 5173 埠。API 代理預設連至 `http://127.0.0.1:8080`，可用 `UMAGUESS_API_TARGET` 調整。若後端限制 Origin，加入實際開發網址

要更新 Go 提供的畫面，重新執行 `make web-build`、`make embed-spa` 並重啟程式

## 手機與平板

裝置連至同一網路，將 IP 換成電腦的區域網路位址

```bash
UMA_ADDR=0.0.0.0:8080 \
UMA_PUBLIC_ORIGIN=http://192.168.1.20:8080 \
UMA_ALLOWED_ORIGINS=http://192.168.1.20:8080 \
make dev
```

手機開啟 `http://192.168.1.20:8080`，並允許防火牆通過該埠。HTTP 區域網路的離線快取能力受安全環境限制

## Docker

```bash
make content-compile
make content-verify
cp .env.example .env
docker compose up -d --build
```

`.env` 用於 Compose 插值，Go 不會自行載入。更換公開網址時，同步設定 `UMA_PUBLIC_ORIGIN` 和 `UMA_ALLOWED_ORIGINS`

題庫以唯讀方式掛載，執行資料與備份使用獨立卷。`docker compose down` 保留資料卷，刪除卷的操作會移除資料
