# 檔案排序

身高、生日與角色小知識，你能排對順序嗎

![檔案排序](../../public/media/play/sort-zh-Hant-desktop.webp)

## 怎麼玩

1. 選擇身高、生日等排序項目，確認這局的排列方向
2. 用上移、下移調整順序，相同數值請合併為並列
3. 按「儲存作答」記錄這版答案，截止前仍能修改再儲存
4. 完成後可交卷立即看結果，逾時以最後儲存的順序計分

## 規則與計分

- 依題目方向排列全部角色，相同數值請合併為並列
- 依每兩位角色的先後與並列關係計分，全部正確得 100 分
- 儲存後可修改，交卷即結束，逾時以最後儲存的答案計分

## 連線遊玩的差異

連線對局由主持人收卷或截止後統一揭曉，儲存後仍須等待

## 手機上玩

用卡片上的上移、下移按鈕調整順序，相同數值可合併為並列
