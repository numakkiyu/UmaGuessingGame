# 遷移至 V2

V2 採用獨立的資料模型與執行方式，舊版的環境變數、資料庫和快取不能直接套用

## 可沿用的內容

角色資料與素材需符合目前格式、來源紀錄與授權條件，再經內容編譯產生新包。舊房間、匿名身分和成績不會自動映射到 V2

## 執行方式

依[快速開始](快速开始.md)建立新資料目錄，使用 V2 設定，重新建置前端與題庫，再將公開網域指向新服務。舊資料以唯讀備份儲存

若要轉移成績，須另外實作欄位映射、身分關聯與去重，不以相同暱稱推定同一人

## 後續更新

V2 內部仍有資料庫、內容包與規則版本。已套用的遷移檔保持不變，結構修改新增遷移。回復方式見[維護與更新](维护与更新指南.md)
