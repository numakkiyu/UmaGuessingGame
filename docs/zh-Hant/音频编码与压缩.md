# 語音素材

角色語音用於[聽音辨角色](play/audio.md)：聽台詞，為每段選擇說話的角色。語音採用 **40 kbps VBR、Opus / WebM**，副檔名為 `.webm`

## 內容與播放

題目使用已試聽並核對說話人與台詞的片段。開始挑戰前準備語音，點選播放後收聽；播放次數與計分規則見玩法說明

語音支援離線儲存，之後在同一瀏覽器中可以繼續使用已儲存的素材

## 格式參數

| 項目 | 設定 |
| --- | --- |
| 目標位元率 | 40 kbps VBR |
| 編碼與容器 | Opus / WebM |
| 取樣率 | 48 kHz |
| 聲道 | 單聲道 |
| HTTP 類型 | `audio/webm; codecs=opus` |
| 檔案限制 | 每段最多 60 秒、2 MB |

## 素材維護

| 路徑 | 內容 |
| --- | --- |
| `data/assets/audio/library/` | WebM 語音檔案 |
| `data/assets/audio/manifest.json` | 來源、檔案摘要、大小與時長 |
| `data/manual/audio-clips.review.json` | 說話人、台詞與試聽核對紀錄 |

檢查完整素材庫：

```bash
pnpm run audio:verify
```

指令逐段解碼並核對清單，CI 執行相同檢查。題包依審校紀錄選用語音，流程見[參與貢獻](参与贡献.md)
