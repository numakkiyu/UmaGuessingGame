# 常見問題

## 單人挑戰需要登入嗎

不需要，普通單人挑戰免登入。站點可為好友、派對與隨機配對分別要求登入，依目前入口提示參加

## 進度存在哪裡

單人進度儲存在目前瀏覽器。更換瀏覽器、網址或清除網站資料後，可能無法直接讀取舊紀錄。支援匯出的玩法可先存成檔案，之後再匯入

## 為什麼少了某個玩法

玩法須同時符合站點開關、人數與題庫條件。缺少圖片、音訊或資料時，對應入口可能關閉，以大廳目前列表為準

## 好友房間與隨機配對有何不同

好友房間用代碼邀請指定朋友，隨機配對則進入公開佇列，配對並確認後開始，不需要好友代碼

## 用完次數就輸了嗎

雙人猜角色使用相同答案，先猜對的人獲勝。用完次數後等待對手完成，尚不公布答案。對手接著猜對仍可獲勝；任一方投降則對手立即獲勝。雙方都沒猜對時，兩人都未獲勝

## 顯示確認作答或重新連線怎麼辦

保持頁面開啟並確認網路，依提示確認原次提交。已記錄的作答不會重複計分。反覆重新整理無法改善連線，部署者可參閱[維護與更新](维护与更新指南.md)

## 手機與語言

手機會切換為卡片或單欄操作，支援版本見[瀏覽器支援](浏览器支持.md)。遊戲依瀏覽器偏好選擇簡中、港台繁中或日文，也可手動切換。文件站的語言選單獨立運作

## 角色名稱為何不同

簡中顯示其他別名、日文、英文與外號；繁中顯示其他譯名、日文與英文；日文顯示日文原名與英文，按地區語境整理

## 這是官方遊戲嗎

這是 BHCN STUDIO 維護的非官方同人開源專案。角色與素材權利歸各權利人所有，詳見[出處與授權](第三方依赖与资料来源.md)
