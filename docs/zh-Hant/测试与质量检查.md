# 開發指令

依修改範圍執行單元測試、靜態分析或建置，在儲存庫根目錄使用

| 指令 | 用途 |
| --- | --- |
| `make test` | Go 單元與整合測試 |
| `make test-race` | 資料競爭偵測 |
| `make fmt-check` | Go 格式 |
| `make vet` | Go 靜態分析 |
| `make web-typecheck` | TypeScript 型別 |
| `make web-lint` | ESLint 與樣式類別 |
| `make web-copy-check` | 玩家文案 |
| `make web-test` | 元件、儲存與指令碼測試 |
| `make web-build` | 前端建置 |
| `make embed-spa` | 將頁面嵌入 Go |
| `make embed-spa-check` | 比對嵌入頁面 |
| `make web-size` | 頁面分塊體積 |

內容測試讀取[編譯後的題庫](内容编译.md)，嵌入頁面測試使用 `make web-build` 與 `make embed-spa` 的輸出。`make web-install` 安裝應用程式與獨立工具鏈的依賴

## API、資料與版面

```bash
pnpm --dir web run api:check
go run ./cmd/content contract --spec api/openapi.json --routes
go test ./internal/e2e/... -count=1
make content-compile
make content-verify
pnpm run audit:layout
```

版面工具使用 Playwright 與獨立執行實例，連線參數見 `web/scripts/audit-layout.mjs`。截圖與報告不加入 Git

## 文件站

```bash
pnpm --dir docs install --frozen-lockfile
pnpm docs:dev
pnpm docs:check
pnpm docs:build

```
