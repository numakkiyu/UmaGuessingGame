# 社群準則

本準則適用於 Issue、Pull Request、程式碼審查及專案協作空間，歡迎不同地區、語言與經驗的玩家和開發者參與

## 交流原則

- 以可重現的問題和依據討論改善方案
- 尊重語言、地區、身分與經驗差異
- 分享素材與資料時附上來源，不將他人成果當作原創
- 區分個人喜好、玩法規則與無障礙需求，接受合理更正

不接受侮辱、騷擾、歧視、威脅、洗版、公開隱私與未經授權攻擊。公開討論勿附 Cookie、驗證碼、資料庫或私有會話

對素材權利、資料或稱呼有異議時，請附來源與修改建議，不將遊戲互動延伸為現實個人的攻擊

## 處理問題

可向維護者提供發生位置、時間與去識別脈絡，漏洞依[私密回報流程](安全策略.md)處理

維護者依影響採取提醒、要求修正、限制互動或移除內容等措施，保護相關者隱私，並讓受處理者透過指定管道說明情況。維護者同樣受本準則約束

GitHub 平台規則與適用法律仍然有效
