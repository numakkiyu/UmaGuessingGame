# 貢獻指南

歡迎修復問題、修正題庫與譯名、改善互動和文件。涉及大幅規則或資料模型變動時，先於 Issue 說明問題與預期行為

## 開始開發

環境與起動步驟見[快速開始](快速开始.md)，`make web-install` 安裝應用程式與獨立工具鏈。文件使用 `pnpm --dir docs install --frozen-lockfile`

## 修改時同步維護

| 對象 | 相關內容 |
| --- | --- |
| API | OpenAPI、生成型別、HTTP 實作、呼叫端與契約測試 |
| 即時通知 | 規格、讀取權限、恢復與重送 |
| 玩法 | 無效輸入、階段、逾時、計分、公開與私有資料 |
| 題庫 | 來源、可信度、修訂與素材審校紀錄 |
| 介面 | 三語、鍵盤、手機、大螢幕與減少動態 |
| 設定 | 預設值、優先順序、容器傳入變數與公開範例 |

規則放在 `internal/modes`，不依賴 HTTP、SQL 或瀏覽器。身分與權限由伺服器會話和房間成員關係決定。控制亂數、順序及計分單位，重送不得重複計分或延長時間

身分、隊伍與主持權以伺服器記錄為準，請求內容的角色宣告僅作輸入。答案按觀看者權限與對局階段提供，前端隱藏不構成保護。題庫變更同步來源、實體分類、審校紀錄與准入報告

## Git 管理範圍

管理原始碼、測試、依賴與鎖定檔、Docker、CI、Make、公開設定，以及有來源的題庫與必要素材

執行資料庫、金鑰、備份、本機設定、日誌、編譯頁面、二進位、內容包、依賴目錄、下載快取與暫存工作檔不加入 Git。`internal/spafs/dist/.gitkeep` 用於維持未建置時的嵌入目錄

音訊素材以 40 kbps VBR、Opus / WebM 儲存於 `data/assets/audio/library/`，`data/assets/audio/manifest.json` 記錄來源、檔案的 SHA-256、大小及時長。加入聽音題前，須在 `data/manual/audio-clips.review.json` 核對說話人、台詞、姓名提示並完成試聽。實際使用的圖片也保留來源，下載快取不提交。單檔上限為 50 MiB

`pnpm run repo:check` 從 Git 索引檢查排除檔案、音訊紀錄與大小，文件和測試須能在全新複製的儲存庫執行

## 持續整合

`.github/workflows/ci.yml` 在推送與拉取請求執行以下檢查

| 範圍 | 檢查內容 |
| --- | --- |
| 儲存庫 | Git 索引、檔案大小、素材來源、音訊格式與工作流程語法 |
| 前端 | 型別、程式碼規範、三語文案、API 引用、測試、建置與資源大小 |
| 伺服器 | 格式、靜態分析、競態測試、覆蓋率與已知漏洞 |
| 題庫與語音 | 完整 WebM 解碼、清單核對、題包編譯與真實題庫判題 |
| 文件 | 三語頁面、連結與 VitePress 建置 |
| 介面與映像 | OpenAPI 型別同步、路由一致性與容器建置 |

覆蓋率報告保留 7 天。`pages.yml` 負責文件站發布；拉取請求的文件建置由 CI 執行
