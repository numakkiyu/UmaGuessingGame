# 文件站維護

文件站使用 VitePress，提供簡中、繁中與日文；README 使用 GitHub 可直接顯示的 Markdown

## 檔案結構

| 路徑 | 用途 |
| --- | --- |
| `README.md` | 簡體中文介紹 |
| `README.zh-Hant.md`、`README.ja.md` | 繁中、日文介紹 |
| `docs/*.md` | 簡中文件 |
| `docs/zh-Hant/`、`docs/ja/` | 繁中、日文文件 |
| `docs/.vitepress/config.mts` | 語言、導覽、搜尋與發布路徑 |
| `docs/.vitepress/theme/` | 首頁與主題樣式 |
| `docs/public/media/` | 遊戲截圖與介紹圖片 |

同一篇文件在各語言目錄保留相同檔名，語言選單即可切換至對應頁面。名稱與敘述按地區調整，API 和程式識別名稱保持原樣

## 本機執行

在儲存庫根目錄執行

```bash
pnpm --dir docs install --frozen-lockfile
pnpm docs:dev
```

開啟終端顯示的網址。文件依賴獨立安裝，不影響遊戲前端的建置

```bash
pnpm docs:check
pnpm docs:build
pnpm docs:preview
```

預設路徑為 `/UmaGuessingGame/`，自訂網域或其他儲存庫名稱可透過 `DOCS_BASE` 調整

```bash
DOCS_BASE=/ pnpm docs:build
```

## GitHub Pages

`.github/workflows/pages.yml` 從 `docs/` 安裝鎖定依賴，建置後上傳 `docs/.vitepress/dist/`

在儲存庫 Settings → Pages 將 Source 設為 GitHub Actions。`main` 的 CI 通過後自動發布對應版本；手動執行也要求目前主線的 CI 已通過。路徑由 Pages 設定取得

Pages 僅提供文件站，遊戲與連線 API 請依[快速開始](快速开始.md)另外部署

## 圖片與文案

README 使用相對圖片路徑、表格、`<picture>` 與摺疊區。GitHub 不執行任意 CSS 或指令碼，複雜版面放在文件站主題中

截圖使用實際遊戲畫面並對應語言，不包含網址列、私人帳號或測試視窗。角色裝飾沿用既有素材，出處與使用條件見[資料來源](第三方依赖与资料来源.md)

介紹頁先說玩法與使用方式，設定和技術資料放到子頁。生成目錄、依賴快取與暫存報告不加入 Git

Logo 與 16:9 主視覺分別使用 `public/media/party-logo.webp` 和 `party-keyvisual.webp`，三種語言共用無字插畫。遊戲的 Logo 副本放在 `web/public/assets/ui/branding/`，替換時一併更新並保留相同檔案摘要

## 玩法圖文與字型

`docs/play/`、`docs/zh-Hant/play/` 與 `docs/ja/play/` 為三語玩法指南，每項包含步驟、規則與手機畫面。截圖放在 `docs/public/media/play/`，依玩法、語言及裝置命名

遊戲與文件各自的 `public/fonts/` 存放地區字型，常用字優先載入，擴充字按需載入。[來源與授權](第三方依赖与资料来源.md)
