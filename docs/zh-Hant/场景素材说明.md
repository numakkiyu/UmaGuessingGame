## 轉換與顯示

現有圖片以最長邊約 1600px、JPEG 品質 65 轉換。macOS 範例

```bash
sips -s format jpeg -s formatOptions 65 -Z 1600 input.png --out output.jpg
```

頁面依容器裁切，以獨立遮罩維持文字可讀性。圖片載入失敗時回退底色或漸層，避免版面塌陷；不要將模糊效果套用到整個內容容器。裝飾須避開焦點、彈出視窗與主按鈕

動態效果遵循系統的減少動態設定，避免持續閃爍
