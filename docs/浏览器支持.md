# 浏览器支持

建议使用最新版本的 Safari、Firefox、Chrome 或 Edge

| 浏览器 | 最低版本 |
| --- | --- |
| Safari | 17.4 |
| Firefox | 128 |
| Chrome | 111 |
| Edge | 111，Chromium 版 |
| iPhone / iPad | iOS / iPadOS 17.4 |

Internet Explorer 和 EdgeHTML 版 Edge 已停止支持。以上为载入条件，实际体验还取决于设备与浏览器设置

## 打开游戏

页面会自动选择简体中文、繁體中文或日本語，也可以从语言菜单切换。浏览器版本过旧时，页面会显示更新方法与官方下载入口

## 声音与保存

听音玩法需要点击播放。听不到时，请检查设备音量、网页静音状态和浏览器的播放权限

单人挑战可以保存进度。使用同一浏览器继续游玩；清除网站数据前，可先导出记录。离线功能需要安全连接，部署建议使用 HTTPS

## 页面打不开时

先确认网络连接，再尝试重新载入。已经提交过答案时，回到原对局确认记录后再继续
