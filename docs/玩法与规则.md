# 玩法与活动说明

这是《赛马娘》主题的非官方娱乐游戏。角色资料可能存在遗漏、不同地区译名和更新延迟，题库不足的玩法会暂时关闭；有问题的条目应附角色名、题目和来源反馈，不把不确定资料当成唯一正确事实

## 先选游玩方式

- **单人**：自己练习，按页面准备资料与开始，记录留在当前浏览器，可用时及时导出
- **多人**：创建房间分享邀请码，朋友输入后加入；邀请了队友就按多人房间参与
- **活动团队**：适合聚会或娱乐赛，主持人安排队伍、回合与大屏，队员按自己的角色参与

建房者担任主持人，可将权限交给房间内符合条件的人。主持人主动离开时，系统从合适成员中交接；网络短暂断开与主动离开不应混为一谈，以房间实际提示为准

昵称下方的六位房间编号用于分辨同名玩家，只在本房间使用。不要将邀请码、大屏配对码或编号当作账号密码分享凭据；重开浏览器或清除数据后，也不能仅凭同一昵称认定身份已恢复

## 每局通用规则

开始前确认本局人数、队伍、限时与信息是否公开。提交后的确认信息和结算页是判断作答是否被接受的依据，按钮按下后断线应先恢复本局，不要反复重新建房

倒计时按本局约定继续，不因刷新重新获得时间。需要多人一致操作的玩法应明确谁能提交，队员讨论不代表每个人都能覆盖队长的最终选择。暂停、认输与再来一局按房间提示确认，不靠关闭页面撤销已经作出的选择

同分时以本局展示规则处理，不默认用网络到达速度决定。活动之间的分数不能直接比较，题库版本、难度及赛程可能不同；本说明不会给所有玩法设置一个实际上不存在的统一计分公式

## 角色知识

### 经典弗一把 · classic

从角色中选择答案，根据逐次显示的九项比较提示缩小范围。相同、接近和不同不仅用颜色，也用符号或文字表示；未知资料不应被解读为“确定不同”

用尽次数、答对、超时或认输后的结算按本局规则显示。经典字段沿用经过整理的比较分组，不把 A～G 适性等级直接当成所有历史字段的替代。练习题可能存在资料向量相同的角色，竞赛题库应排除无法区分的答案

### 适性交叉占格 · aptitude-grid

横纵条件相交形成目标格，从候选角色中选择符合两边条件的人选。关注场地、距离和跑法等要求，不能只看其中一个条件。重复使用、占格及队伍轮次以当前棋盘限制为准，已经被服务端拒绝的选择不算成功占格

### 档案排序 · sort

按本局指定的身高、生日等字段排列角色，需要并列时手动合并成组。初始顺序不是答案，不自动把数值相同的角色归为并列。结算比较相对次序及并列关系，不只看是否站在某个绝对位置

开卷与闭卷影响作答时能看到的资料；不要在不知道本局规则时将某个字段缺失视为应排在最前或最后

### 血统 · pedigree

根据公开候选补全原型马的亲缘关系。角色和现实原型马不是同一个实体，关系以题目引用的资料为准，不依据角色剧情猜测现实血统

合作局可共同完成关系槽位，个人贡献与团队结果按结算分别展示。缺失来源或关系信息不足的家系不应进入要求唯一答案的题目

## 观察与记忆

### 学园记忆翻牌 · memory

记住牌面后寻找相同配对。先准备好图片，再进入观察与作答时间，图片加载失败不能消耗玩家的完整观察机会。翻牌次数、失误与剩余时间按本局规则记录，刷新不能重置

这里考观察和记忆，不要求通过公开角色名反查整盘答案。手机棋盘应能完整操作，减少动态时仍能分辨牌面朝向和匹配结果

### 听音辨马 · audio

听片段并选择角色，按本局限制播放与作答。声音应由玩家主动开始，避免进入页面突然外放；听不见时先检查静音、音量与素材可用性

该玩法需要可解码、来源清楚且经审校的片段。只有远端 URL 或未审校台账不能保证开放，当前内容不足时入口应说明暂不可用，不用虚构音频代替

## 历史与关联

### 历史赛况复原 · race-rebuild

根据题目给出的赛事信息与参赛者恢复名次关系。缺失名次的参赛记录可能被排除，保留原名次空档，不把剩余参赛者重新编号成另一场结果。并列关系按资料与本局规则处理

结算按有效参赛者的顺序关系评估，不能把候选列表的初始位置当作提示

### 同场之路 · co-race-path

从起点角色连到目标角色，相邻两位之间需要有题库认可的同场参赛关系。每段连接都应能在揭晓时看到对应赛事依据，不能只因两位角色在剧情中相识就当作有效连接

路径长度、重复节点和提交次数按本局限制处理。记录不完整时不代表现实中绝无同场经历，只表示本题库没有可用于裁决的依据

## 编队与策略

### 公开编队 · draft

在给定卡池和预算内组建阵容，满足本局任务。需要同时考虑花费、适性和任务组合，不能超预算或重复使用被限制的卡片。确认后的最终阵容才进入结算，拖动中的草稿不等于已经提交

### 回合制策略赛道 · strategy-race

各队按回合选择行动，结合体力、位置和赛道规则推进。选择以已确认动作和回合结果为准，动画用于解释移动，不负责决定胜负。超时、断线或刷新都不能重复应用上回合效果

这是独立的娱乐策略玩法，不宣称复现官方游戏的真实比赛模拟。活动前应先让玩家熟悉行动与体力规则

### 档案交易 · trade

围绕公开目标交换手中的卡牌。提案展示要给出和希望换入的具体卡片，只有对方接受并通过当前持有与阶段检查后才成交；被拒绝、过期或撤回的提案不能转移卡片

同一张卡片不能被重复成交，不因先后看到不同页面就获得第二份。该玩法依赖多人协商，部分部署默认关闭，不能作为完全单人练习宣传

## 聚会与合作

### 团队情报拼图 · clue-puzzle

队友掌握不同线索，通过讨论补全整体方案。每个人只看自己的允许信息，主持与大屏也不提前公开全部秘密。提交前检查所有条件，不将“满足一条线索”误认作全部正确

题目需要可解且符合唯一性要求，缺少线索或存在多个未说明答案时不能正常计分。适合讨论型活动，现场应预留交流时间

### 默契问答 · rapport

一位玩家选择自己的答案，其他人猜他会选什么。这里考伙伴默契，没有全体玩家都必须认同的“官方偏好”。按本局轮次轮换角色，在揭晓前保护选择与预测

未作答不凭空补一个偏好，未完成的预测仍按本局固定规则处理。主持人不能在看到选择后临时调整计分方式

### 创意企划 · creative

围绕题目写作品或点子，再进入匿名展示与投票。写作、审核与投票有不同阶段，不能提前看到不该公开的内容。遵守长度要求与社区行为准则，主持人可按事先约定处理违规作品

默认娱乐奖不计入竞技总分；如活动启用少量奖励，额度在开局前固定。观众票与团队票按本局规则分别展示，不临时让人气投票决定整个赛事

### 假档案发布会 · bluff

围绕一条有来源的真实资料提交迷惑选项，再在匿名选项中找出真相。相同提交合并处理，不能投自己的假答案，揭晓时说明真相与得分依据

该玩法依赖真实资料的语义审校，不只校验 JSON 格式。未审校事实不会作为“已证实真相”开放，当前仍需按内容准入结果判断能否使用

## 举办一场娱乐赛

建议先用熟悉的角色猜谜或翻牌热身，再安排一项团队讨论，最后以策略或创意环节收尾。这是主持建议，不是自动生成赛程或已验证平衡的承诺

开场明确队伍、赛程、计分、暂停方式与断线处理；投影只展示允许公开的信息。不同设备使用相同规则，大屏不提供玩家操作凭据。需要裁决的争议依据题目来源与已确认结果处理，不靠临时修改题库让某队获胜

现场至少演练一次主持权转交、队员重连、大屏恢复与整局结算。开始前确认所需玩法均已开放，音频可用，设备网络允许实时连接；配置、容量和运维见[配置参考](配置参考.md)及[维护指南](维护与更新指南.md)
