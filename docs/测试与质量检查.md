# 开发命令

开发工具用于运行单元测试、分析代码和构建应用，按修改范围选择命令即可

## 应用与规则

| 命令 | 用途 |
| --- | --- |
| `make test` | Go 单元与集成测试 |
| `make test-race` | 数据竞争检测 |
| `make fmt-check` | Go 格式 |
| `make vet` | Go 静态分析 |
| `go test ./internal/e2e/... -count=1` | HTTP、SQLite、题库与规则组合测试 |

内容相关测试读取编译题库，构建方式见[内容编译](内容编译.md)。前端嵌入测试读取构建后的页面，使用 `make web-build` 和 `make embed-spa` 更新

## 前端

| 命令 | 用途 |
| --- | --- |
| `make web-typecheck` | TypeScript 类型 |
| `make web-lint` | ESLint 与样式类名 |
| `make web-copy-check` | 玩家文案禁用词 |
| `make web-test` | 组件、交互、存储与脚本测试 |
| `make web-build` | 生成应用页面 |
| `make web-size` | 首屏与分块体积 |
| `make embed-spa` | 将页面复制到 Go 嵌入目录 |
| `make embed-spa-check` | 比对嵌入页面与当前构建 |

`make web-install` 安装应用与隔离工具链依赖。`make check` 汇总本地开发命令，`make ci` 另含接口契约比较

## 接口与资料

```bash
pnpm --dir web run api:check
go run ./cmd/content contract --spec api/openapi.json --routes
make content-compile
make content-verify
```

接口说明见 [API 与实时通信](API与实时通信.md)，资料结构见[内容编译](内容编译.md)

## 布局工具

```bash
pnpm run audit:layout
```

工具使用 Playwright 和独立运行实例，连接地址及参数见 `web/scripts/audit-layout.mjs`。产生的截图和报告不加入版本控制

## 文档站

```bash
pnpm --dir docs install --frozen-lockfile
pnpm docs:dev
pnpm docs:check
pnpm docs:build
pnpm docs:preview
```

文档站使用独立锁文件，详细目录和 Pages 设置见[文档维护](文档维护.md)
