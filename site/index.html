赛马娘猜猜乐

一个围绕赛马娘角色资料设计的开源网页猜谜项目。这个页面用于 GitHub 上的轻量演示展示， 正式可交互站点仍建议部署到支持 Next.js、PostgreSQL 与 Redis 的运行环境。

查看 GitHub 仓库 阅读项目文档

项目亮点

  • 单人模式已经具备完整对局流程、分享与只读查看能力。
  • 多人匹配与好友对战已经具备房间、同步和安全校验基础结构。
  • 图片交付采用受控回源与本地缓存复用策略。
  • 仓库自带 Docker、CI、Issue 模板、PR 模板和部署文档。

技术架构

  • Next.js 16 + React 19 + TypeScript
  • PostgreSQL + Drizzle ORM
  • Redis + Cloudflare Turnstile
  • Docker Compose / PM2 / Nginx

推荐部署方式

  • 本机试玩：Windows 或 macOS 使用 Docker Desktop
  • 正式上线：Linux 服务器使用 Docker Compose 或 PM2 + Nginx
  • 面板运维：宝塔面板或 1Panel
